# TiendaPy - Sistema de Gestion

Aplicacion de consola desarrollada en Python para el control de inventario, ventas y caja de la tienda "Don Aurelio".

## Instalacion y ejecucion

1. Crear y activar el entorno virtual:
   python -m venv venv
   .\venv\Scripts\activate

2. Instalar dependencias:
   pip install -r requirements.txt

3. Ejecutar aplicacion:
   python src/main.py
